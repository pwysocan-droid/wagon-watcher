# dealers.md: call log and dealer notes

A human-readable log of every dealer contact during the buying window. It
mirrors each candidate's `call_log` in `config/decision_queue.json`. Write
an entry the **same day** as the call: spoken details fade within about 48
hours, and a quoted number is only leverage once it's written down. See
MARKET_NOTES.md, "Endgame manual layer".

Newest entries on top within each dealer.

## Entry template

```
### YYYY-MM-DD HH:MM PT · <dealer> · <VIN suffix> · call|email|text
- Spoke to:
- Quoted: price / out-the-door / fees / add-ons
- Docs promised (and by when): CPO sheet, Carfax, AutoCheck, in-service date, walkaround video
- Red flags:
- Next step:
- Confirmed in writing? (email sent Y/N)
```
